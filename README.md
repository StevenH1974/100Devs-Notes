# 🚀 #100Devs — Full Stack Software Engineering Notes & Portfolio Logs

## 📖 About #100Devs
**#100Devs** is an intensive, 30-week, 60-lecture full-stack software engineering bootcamp led by Leon Noel. The curriculum is designed to take engineers from computer science fundamentals to building, deploying, and maintaining production-grade web applications. 

The program emphasizes:
- Writing clean, accessible, semantic code from scratch.
- Industry-standard engineering workflows (Git, GitHub, terminal tooling, deployment pipelines).
- Daily deliberate practice, spaced repetition, and active recall.
- Agile collaboration, technical writing, and professional networking.

---

## 🎯 About This Repository
This repository serves as a centralized, living log of my coursework, self-directed research, and practical exercises throughout the cohort. It contains:

* **Comprehensive Class Notes:** Detailed summaries of lectures, design patterns, and engineering concepts organized by class milestone.
* **Active-Recall Flashcard Logs (Anki):** High-yield technical flashcards cataloging definitions, mechanics, syntax, and best practices to ensure long-term mastery.
* **Layout Reconstructions & Homework Builds:** Hands-on markup and styling exercises reverse-engineering real-world production platforms (e.g., BBC, TechCrunch, Khan Academy).
* **Foundational Readings & Reference Notes:** Key takeaways from foundational texts, including Shay Howe's *Learn to Code HTML & CSS*, *Learn Layout*, and freeCodeCamp certification modules.

---

## 🛠️ Roadmap & Core Stack Overview

### Phase 1: Client-Side Foundations *(Current Milestone)*
* **Semantic HTML5:** Document flow, landmark architecture (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`), forms, data tables, and web accessibility standards (ARIA/WCAG).
* **Modern CSS & Layout Systems:** The Cascade, Specificity, Box Model mechanics, positioning, typography, responsive design, Flexbox, and CSS Grid.
* **Architectural Principles:** Separation of concerns, progressive enhancement, and wireframe-driven development.

### Phase 2: JavaScript & Modern Web APIs
* Core JavaScript syntax, data types, control flow, functions, and DOM manipulation.
* Object-Oriented Programming (OOP) and modern ES6+ features.
* Asynchronous JavaScript: Event loop, Promises, `async/await`, and interacting with third-party REST APIs.

### Phase 3: Backend, Databases & Full-Stack Applications
* Node.js runtime environment and Express framework.
* Database design and management with MongoDB and Mongoose.
* MVC architecture, authentication, server-side rendering, and RESTful API design.
* Full-stack application deployment, CI/CD, and production monitoring.
