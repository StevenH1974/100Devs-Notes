## Web Fundamentals & Architecture
1. **Front:** What does "Separation of Concerns" mean in web development?
   **Back:** The architectural principle of separating a website into three distinct layers: HTML for structure/content, CSS for presentation/appearance, and JavaScript for behavior/interactivity.

2. **Front:** What is "Progressive Enhancement" in web design?
   **Back:** The practice of building a fully functional, semantic HTML baseline for all users first, then progressively layering CSS styling and JavaScript interactivity for modern browsers/faster connections.

3. **Front:** Why should you sketch or wireframe a layout before writing HTML?
   **Back:** To visually identify structural containers (`<header>`, `<nav>`, `<section>`, `<article>`, `<footer>`) and nested relationships before writing code, preventing messy DOM hierarchies.

4. **Front:** What is the semantic HTML pattern for a clickable news headline?
   **Back:** An anchor tag nested inside a heading element (e.g., `<h3><a href="/article">Headline Text</a></h3>`).
