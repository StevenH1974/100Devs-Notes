# 🚀 #100Devs — Class 03: HTML Review & Layout Fundamentals

## 📌 Class Overview
- Final core HTML lecture focusing on layout architecture, progressive enhancement, wireframe thinking, and analyzing production websites.

## 📝 Key Lecture Concepts
- **Separation of Concerns:** 
  - HTML = Content & Semantics (The structure)
  - CSS = Presentation & Layout (The styling)
  - JavaScript = Behavior & Client-side Scripting (The interactivity)
- **Progressive Enhancement:** 
  - Build core accessible content first (e.g., text-only accessible versions like `lite.cnn.com`).
  - Layer presentation (CSS) next, then interactive scripts (JS). Essential for users with slow connections, older devices, or assistive technology.
- **Wireframing Before Coding:**
  - Always sketch or map out the layout on paper first.
  - Identify bounding boxes: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`.
- **Navigation (`<nav>`) Patterns:**
  - Top navigation and sidebars.
  - Lists with anchor tags (`<nav><ul><li><a href="...">Link</a></li></ul></nav>`).
  - Search bars and branding logos inside or alongside navigation wrappers.
- **Deconstructing Production Sites:**
  - Analyzed layout anatomy of TechCrunch and Khan Academy.
  - Using headings wrapped in anchor tags (`<h2><a href="...">Article Title</a></h2>`) for semantic, clickable story cards.
